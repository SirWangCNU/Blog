# 个人博客后台界面设计（方案 A）

## 目标

为单管理员个人博客提供朴素、清晰、适合长期高频使用的管理界面。设计参考主流中后台产品的经典布局，不追求展示型视觉效果；界面应让用户快速定位博客、作品、媒体和网站设置，并清楚识别当前状态与主要操作。

本轮只重构后台界面。管理员登录、SQLite 内容层、博客 CRUD、媒体库和网站设置仍按既定后端计划逐步接入，不在纯前端中伪造功能。

## 视觉原则

- 使用常规无衬线字体，不使用宋体、展示字体或等宽字体作为大面积正文。
- 使用浅灰页面背景、白色容器、浅灰边框和单一蓝色主色。
- 不使用纹理背景、巨大标题、英文装饰眉题、装饰编号、强烈色块或复杂入场动画。
- 阴影仅用于浮层；普通卡片以边框区分层级。
- 图标只帮助识别功能，不承担装饰作用。
- 信息密度适中，桌面端优先保证列表、表格和编辑表单的效率。

## 设计变量

- 字体：`-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`
- 页面背景：`#f5f7fa`
- 容器背景：`#ffffff`
- 侧栏背景：`#ffffff`
- 主文字：`#1f2937`
- 次文字：`#6b7280`
- 边框：`#e5e7eb`
- 主色：`#1677ff`
- 成功：`#16a34a`
- 警告：`#d97706`
- 危险：`#dc2626`
- 正文：14px / 22px
- 页面标题：24px / 32px，600 字重
- 区块标题：16px / 24px，600 字重
- 统计数字：28–32px，600 字重
- 圆角：表单和按钮 6px，卡片 8px
- 间距：以 8px 为基准，常用 8、12、16、24、32px

## 全局布局

桌面端使用经典左侧导航和顶部工具栏：

- 侧栏固定宽度 220px，可折叠到 64px。
- 顶栏固定高度 56px，包含侧栏折叠按钮、面包屑、查看前台入口和管理员菜单。
- 主内容区背景为浅灰色，内容最大宽度 1440px，内边距 24px。
- 侧栏仅显示站点名称、五个主要模块和底部版本信息，不显示个人档案卡或服务状态装饰。
- 当前导航使用淡蓝背景和蓝色文字，不使用粗色条或整块深色背景。

移动端隐藏侧栏，通过顶栏菜单按钮打开抽屉；内容区内边距缩小到 16px，统计卡片改为单列或双列，表格允许横向滚动。

## 总览页

总览页按常见后台结构排列：

1. 面包屑和页面标题“控制台”。
2. 右侧主要操作“新建作品”。博客 CRUD 接入后再增加“写文章”。
3. 四个统计卡片：博客文章、作品总数、已发布作品、草稿数量。
4. 主区域左侧为最近作品表格，列出名称、状态、更新时间和操作。
5. 主区域右侧为最近文章列表和系统提示。

不显示装饰性的 `ON`、英文标签、路线图编号和大面积安全提示。安全未完成时仅在页面顶部使用标准警告提示条。

## 作品管理页

- 页面头部包含面包屑、标题、说明和“新建作品”按钮。
- 内容区使用白色卡片承载工具栏和表格。
- 工具栏预留搜索、发布状态筛选和分类筛选；在数据量较少时仍保持简洁。
- 表格列为封面、作品名称、分类、状态、更新时间、操作。
- 编辑为普通文字按钮，删除使用危险色并保留确认对话框。
- 空状态使用简单图标、两行说明和一个主按钮，不使用展示型文案。

## 编辑页

- 使用标准页面标题和返回链接。
- 表单分为“基本信息”“链接与标签”“图片”“项目详情”四个白色卡片。
- 桌面端基本信息可两列排列，Markdown 编辑区保持全宽。
- 底部操作栏提供“保存草稿”和“发布”，在长表单中保持清晰可见。
- 输入框、下拉框和上传区域遵循统一边框、圆角和焦点状态。

## 待接入页面

博客、媒体库和网站设置继续保留路由，但改为普通空状态页面：标题、简短说明、功能清单和“即将开放”状态。删除巨大编号和海报式排版。

## 组件边界

- `AdminShell`：侧栏、顶栏、移动抽屉和主内容容器。
- `AdminDashboard`：统计卡片、最近作品、最近文章和系统提示。
- `AdminPageHeader`：面包屑、标题、说明与操作区。
- `AdminRoutePlaceholder`：未接入模块的标准空状态。
- `admin-navigation.ts`：导航配置与路径激活规则。
- `dashboard.ts`：将真实作品和文章数据映射为总览视图模型。

## 交互与可访问性

- 所有按钮和链接提供明确的可访问名称与键盘焦点。
- 当前导航设置 `aria-current="page"`。
- 移动抽屉支持 `aria-expanded`，路由跳转后自动关闭。
- 状态不仅依靠颜色区分，还显示文字标签。
- 遵守 `prefers-reduced-motion`；只保留抽屉和下拉菜单所需的短过渡。

## 数据与错误状态

- 总览继续读取现有真实作品与博客数据，不展示虚构图表。
- 加载使用简洁骨架屏；空状态提供下一步操作。
- 读取失败使用页面内错误提示，不让整个后台白屏。
- 当前未完成登录，正式上线后台前仍必须封锁 `/admin`、草稿读取和写操作 API。

## 验收标准

- 后台仅使用无衬线字体，页面标题不超过 24px。
- 无纸张纹理、宋体大标题、英文装饰眉题、红色大色块和展示型编号。
- 桌面端为 220px 浅色侧栏、56px 白色顶栏和浅灰工作区。
- 总览为标准统计卡片、表格和列表布局。
- 作品列表与编辑页使用一致的卡片、表格、表单和按钮样式。
- 公开站点的 Header、Footer 和粒子背景不出现在后台。
- 桌面和移动端均可操作，现有作品 CRUD 行为不回归。
- 自动化测试、相关 Lint 和生产构建通过。
- 不执行 Git 提交。
